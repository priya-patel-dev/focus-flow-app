# Focus Flow

A productivity and focus management application designed to help users organize tasks, improve daily momentum, and build better work habits.

## Overview
Focus Flow is a clean productivity app for users who want to stay organized without feeling overwhelmed. It helps people plan their workday, prioritize tasks, and maintain a healthier focus rhythm.

## Features
- Task prioritization and planning
- Daily productivity workflow
- Focus-friendly user experience
- Habit and goal tracking
- Minimal, distraction-free dashboard

## Tech Stack
- Frontend: React + TypeScript
- Styling: CSS / component-driven design
- Deployment: Vercel

## Run locally
```bash
npm install
npm run dev
```

## Project goal
To build a calm, motivating workspace that helps users stay productive and consistent without burnout.
